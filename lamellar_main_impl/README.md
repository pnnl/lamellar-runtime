lamellar_main_impl
===================

Proc-macro implementation crate for `#[lamellar_main::main]`/`#[lamellar_main::test]`. Not intended to be depended on directly — use [`lamellar_main`](../lamellar_main/README.md) instead, which reexports these macros and provides the runtime support functions they call into.

hpc_launch_impl
===============

Proc-macro implementation crate for `#[hpc_launch::main]`/`#[hpc_launch::test]`. Not intended to be depended on directly — use [`hpc_launch`](../hpc_launch/README.md) instead, which reexports these macros and provides the runtime support functions they call into.
